There is a nice cross-platform open source tool to find out what the best DNS server is for your internet connection.

1. Go to [https://code.google.com/p/namebench/downloads/list](https://code.google.com/p/namebench/downloads/list)
1. Download the namebench tool
1. Extract and start the tool
1. Click on "Start Benchmark

[![2015-08-19 23_40_10-namebench](/wp-content/uploads/2015/08/2015-08-19-23_40_10-namebench.png)](/wp-content/uploads/2015/08/2015-08-19-23_40_10-namebench.png)

This benchmark takes some time. About +/- 15 minutes. Then you get the results in your browser:

[![DNS-Namebench1](/wp-content/uploads/2015/08/DNS-Namebench1.png)](/wp-content/uploads/2015/08/DNS-Namebench1.png)[![DNS-Namebench2](/wp-content/uploads/2015/08/DNS-Namebench2.png)](/wp-content/uploads/2015/08/DNS-Namebench2.png)

201% faster name query performance!!! WOW!

When everything is setup you can check your DNS settings with a nice website: [https://www.dnsleaktest.com/](https://www.dnsleaktest.com/) [![2015_08_19_23_34_48_Store](/wp-content/uploads/2015/08/2015_08_19_23_34_48_Store.png)](/wp-content/uploads/2015/08/2015_08_19_23_34_48_Store.png)

To find the best DNS server for you start the tool at different times during the day.

Happy resolving :-)
