Hi,

To create a connection between your Hyves and your wordpress blog follow this steps:

1. Create an hyves API key @ http://www.hyves.nl/api/ ([in detail](http://wp-hyves.hyves.nl/forum/2835704/eoxR/Installation_Tutorial_5_Steps_in_getting_WP_Hyves_to_work/))
1. Install the WP-Hyves plugin in your Wordpress
1. Insert the API keys in the plugin

After your published a post in WP  you can publish it to hyves:
