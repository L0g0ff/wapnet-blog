There is a nice tool to manage your phone directly from your pc.

See screen:

![mobilephone](/wp-content/uploads/2009/11/mobilephone1.png)

Step1: You can download the software here [MyMobile123.zip](/wp-content/uploads/2009/11/MyMobile123_06152008.zip)
Step2: Extract the zip
Step3: Connect with activesync
Step4: start > run > C:\\path-to-extracted-zip\\MyMobiler.exe -connect

Official site: [http://www.mymobiler.com/](http://www.mymobiler.com/)
