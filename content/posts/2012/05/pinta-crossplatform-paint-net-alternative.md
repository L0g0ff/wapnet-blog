Today I found a very nice cross platform Paint.NET program clone with the name Pinta.

Now I can edit images on every platform (OSX, Linux & Windows) and use always the same interface and hotkeys for the few times a year I need a simple paint prgram.

When you install the software under windows do not forget to install the "[Gtk# for Windows](http://ftp.novell.com/pub/mono/gtk-sharp/gtk-sharp-2.12.9-2.win32.msi)". Without the GTK the program don't start and don't give any error.

You can find the software here: [http://pinta-project.com/](http://pinta-project.com/) [![](/wp-content/uploads/2012/05/Pinta-Screenshot.jpg)](/wp-content/uploads/2012/05/Pinta-Screenshot.jpg)
