You need:

- A 1GB USB stick  for Windows xp or 2GB for higher os
- A Windows OS to run the tool
- The tool [Novicorp WintoFlash](http://wintoflash.com/download/en/) (tool is multilanguage)
- a Windows installation CD or extracted installation directory

Steps:

1. Extract the WintoFlash tool
1. Start the tool
1. Follow the wizard
1. [![](/wp-content/uploads/2012/01/wizard1.jpg)](/wp-content/uploads/2012/01/wizard1.jpg)
1. Set source (Windows installation files or CD)
1. [![](/wp-content/uploads/2012/01/wizard2.jpg)](/wp-content/uploads/2012/01/wizard2.jpg)
1. Now complete the wizard and your stick is ready for use

Now you NEVER need a stupid CD anymore for Windows installation purposes :)

Note: if you have some trouble with the windows activation [try these steps](/2012/03/windows-7-error-cant-activate-0x8007007b/ "Windows 7 error can’t activate 0x8007007B")
